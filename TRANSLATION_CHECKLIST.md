**Functionality**:
- ⬜ English text displays correctly
- ⬜ Spanish text displays correctly
- ⬜ Language switcher works on this page
- ⬜ Links/buttons still work
- ⬜ Forms submit properly (if applicable)
- ⬜ No console errors

**Layout**:
- ⬜ Spanish text doesn't overflow containers
- ⬜ Buttons don't wrap awkwardly
- ⬜ Card heights are consistent
- ⬜ Mobile layout works in both languages
- ⬜ No horizontal scrolling

**Translation Quality**:
- ⬜ Spanish sounds professional
- ⬜ No machine translation artifacts
- ⬜ Tone matches English version
- ⬜ CTAs are compelling in both languages
- ⬜ Technical terms translated correctly

## 🚀 Deployment Checklist

Before pushing to production:

**Pre-Deploy**:
- ⬜ All 7 pages/components translated
- ⬜ No hardcoded English text remaining
- ⬜ All translation keys exist in both en.json & es.json
- ⬜ Dev server tested thoroughly
- ⬜ No console errors in either language
- ⬜ Mobile responsive in both languages

**Deploy**:
- ⬜ `npm run build:production` succeeds
- ⬜ Preview build locally (`npm run preview`)
- ⬜ Test critical user flows in Spanish:
  - ⬜ Contact form submission
  - ⬜ Booking form submission
  - ⬜ Navigation between pages
- ⬜ Commit with clear message
- ⬜ Push to GitHub
- ⬜ Monitor deployment logs

**Post-Deploy**:
- ⬜ Visit live site, switch to Spanish
- ⬜ Click through all pages
- ⬜ Submit test contact form in Spanish
- ⬜ Verify language persists across navigation
- ⬜ Check on mobile device
- ⬜ Share with Spanish-speaking tester for feedback
